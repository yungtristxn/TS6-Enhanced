# TS6 Enhanced

More room for streams in TeamSpeak 6, with collapsible previews, chat that keeps updating while hidden, and stream volume up to 300%.

For Windows x64 and TeamSpeak 6.0.0-beta5 (build 1791901251).

[Download the installer](https://github.com/yungtristxn/TS6-Enhanced/releases/latest), then open TeamSpeak from the **Start Menu**. Finish any calls or streams first, as setup may restart the client.
