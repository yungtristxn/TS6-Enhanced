# TS6 Enhanced

More room for streams in TeamSpeak 6, with collapsible previews, chat that keeps updating while hidden, stream volume up to 300% remembered per streamer, tidier channel chat, a poke sound and taskbar flash for every poke, and confirmed updates that restore your server/channel, shared stream and audio state. Each feature can be switched off in the TS6 Enhanced dialog.

For Windows x64 with TeamSpeak 6 installed for your Windows account. Each release is verified with one TeamSpeak build (currently 6.0.0-beta5.1); when TeamSpeak updates itself, TS6 Enhanced keeps running in compatibility mode and can still update itself.

[Download TS6 Enhanced](https://github.com/yungtristxn/TS6-Enhanced/releases/latest), run the installer, then open TeamSpeak normally. Setup restarts the client, so finish any calls or streams first.
