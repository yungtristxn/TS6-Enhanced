# Setup

Requires Windows x64 and the standard per-user installation of TeamSpeak 6.0.0-beta5.

Run the installer and click **Install**. Setup uses Windows PowerShell 5.1 and downloads Node if needed. Finish calls or streams first, as setup restarts TeamSpeak.

Open TeamSpeak from the **Start Menu** after installation.

## Update or uninstall

Open **TS6 Enhanced** in the toolbar. Updates are checked at startup and every six hours; **Check for updates** checks immediately. Installing an update preserves your settings and restarts TeamSpeak.

Choose **Uninstall…**, or remove TS6 Enhanced through Windows Installed apps. Removal restores your saved appearance and original shortcut while keeping accounts and chats.

## Help

Logs and recovery files are stored in `%LOCALAPPDATA%\TS6-Layout`.

To start the native client directly, open `%LOCALAPPDATA%\Programs\TeamSpeak\TeamSpeak.exe`.
