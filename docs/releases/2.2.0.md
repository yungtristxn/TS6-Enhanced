Confirmed updates can now restart TeamSpeak, install the verified package, reconnect to the previous server/channel, and resume matching shared streams and mute state. Audio restores before capture discovery or watched-stream waits.

- Keeps the native start-stream dialog and source picker, with refined Pause, Settings, Stop and viewer controls while sharing.
- Fixes old Enhanced theme conflicts that could collapse the sharing bar.
- Preserves newer mute/call choices during recovery, handles Hide on Close, and prevents relaunched clients from retaining old updater helpers.
- Keeps interrupted and partially installed updates visible and retryable. Protected draft recovery no longer blocks later updates.
- Removes the retired CSS-only updater, beta4 stream adapter, redundant setup layer and unused packaged development files. Recovery and uninstall support for existing installations remain.

Requires Windows x64 and TeamSpeak 6.0.0-beta5, build 1791901251.

**Upgrade note:** the initial upgrade from 2.1.x uses the old update flow. Finish calls and streams before running the installer. Confirmed restart/session restoration applies to future updates from 2.2 onward.

**Known limitation:** watched streams may require manual rejoin. Private/group calls, fullscreen, unsent attachments and other states that cannot be restored safely block the automatic restart. Missing or changed capture sources remain stopped.

Validation includes isolated native restart/installer recovery tests and a local live check of reconnect, the user's shared stream and audio state. Faster audio ordering and subsequent cleanup were verified with regression tests; this is not a guarantee for every device or capture source.
