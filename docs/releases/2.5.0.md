Pokes you can't miss: a sound and a taskbar flash for every poke.

- Every poke now plays TeamSpeak's poke sound. TeamSpeak 6 tied it to the "message received" sound, so turning off chat sounds also silenced pokes, and it stayed quiet while you were away or had your speakers muted. If TeamSpeak already played the sound, it is not repeated. A notification device set to "None" keeps it silent.
- While TeamSpeak is in the background, a poke from any server tab flashes it in the taskbar. TeamSpeak 6 did this only for the server tab you had open. TeamSpeak's own "flash taskbar on poke" setting still applies.
- TeamSpeak's own poke card is unchanged.
- Both are on by default and can be switched off separately on the Chat tab of the TS6 Enhanced dialog: **Poke sound** and **Flash taskbar on any poke**.

Requires Windows x64 and TeamSpeak 6.0.0-beta5, build 1791901251.

Validation includes the core, browser and native suites, and a live check of the poke sound and taskbar flash in the client.
