A steadier stream grid, a continuous footer line and easier column resizing.

- Returning from a focused stream to the grid now shows the streams side by side at equal size. With chat hidden, TeamSpeak's grid previously put one stream across the full width and shrank the others to a thin row, so the grid looked like another stream had been focused.
- Clicking the focused stream returns to the grid reliably: a delayed click on another tile can no longer land afterwards and focus a different stream.
- With several streams, the view-actions strip spans the whole stage and, with chat hidden, matches the side footers' height, so the footer line runs across the window without a gap or step.
- The rounded notch at the top-left corner of the middle column is gone.
- Column edges show a faint divider where you can drag to resize; it turns into an accent line on hover and while dragging.

Requires Windows x64 and TeamSpeak 6.0.0-beta5, build 1791901251.

Validation includes the core, browser and native suites, and a live check in the client: real clicks on both an incoming and your own stream, stable layout with no repeated DOM changes at rest, and equal grid tiles.
