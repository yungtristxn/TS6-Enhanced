Tidier channel chat, volume remembered per streamer, feature switches and an aligned channel tree.

- Join, leave, disconnect and timeout messages are slim single lines with the time beside the text, without the card background.
- Three or more consecutive join/leave events fold into their latest line with a **+N more** button that expands and folds them again. Kicks, bans, pokes and text messages stay visible. TeamSpeak's option to hide system messages still applies.
- Chat lines stop at a readable width in wide windows. The stream stage above a channel chat keeps the full width.
- Your last stream volume for each streamer is reapplied when you watch them again. Volumes restored after an update and volumes you already changed are kept.
- The TS6 Enhanced dialog has switches for click-to-focus, the 300% volume control, volume memory and each chat change. They apply immediately.
- The TS6 Enhanced toolbar button has its own sparkle icon instead of a copy of the TeamSpeak settings cog.
- Channel tags, expand arrows and client badges line up in one column on the right of the channel tree, with or without subchannels.

Requires Windows x64 and TeamSpeak 6.0.0-beta5, build 1791901251.

Validation includes the core, browser and native regression suites. The chat grouping uses TeamSpeak's own chat filter methods in tests with synthetic messages; it has not yet been used on a live server.
