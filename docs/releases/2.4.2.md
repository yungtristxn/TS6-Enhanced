A tidier settings dialog, chat back at the top, one-click updates and cleaner update restarts.

- The TS6 Enhanced dialog has Streams, Chat and Updates tabs instead of one long list. It opens on Updates while an update waits, remembers the last tab, and keeps Uninstall separate at the bottom of the Updates tab.
- Channel chat starts at the top again. Anchoring messages to the message box is now the optional switch "Messages start at the bottom" (off by default).
- **Update** in the update popup starts the update right away; the popup shows its progress.
- Before restarting for an update, TeamSpeak leaves your servers cleanly. A crash in TeamSpeak's own shutdown can then no longer leave a lingering session that makes you rejoin as "Name1". Session restoration reconnects you as before.
- Downloaded installers are removed once they are installed, freeing space in `%LOCALAPPDATA%\TS6-Layout\updates`.

Requires Windows x64 and TeamSpeak 6.0.0-beta5, build 1791901251.

Validation includes the core, browser, native and installer suites. The clean disconnect and installer cleanup apply to updates from this version onward.
