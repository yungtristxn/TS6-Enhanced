Consistent headers, footers and active states, checked against the live client.

- TeamSpeak's built-in theme loaded after the layout and silently overrode about 120 of its rules. The layout now follows the active built-in theme, including after a light/dark switch, while a custom theme you select still takes precedence.
- The server header in the channel tree is a flat title row level with the chat and settings headers, sharing one continuous divider. The talk-power notice sits below it, aligned with the channel rows.
- The search row, server header and detail header line up at the same height, and the sidebar and tree footers share one divider.
- The active channel and server header use the same accent bar instead of an outline box.
- Channel tags lose their dark glow, client badges lose their dark boxes, and the header's info/chat/files switch highlights the selected view.
- Create Channel is a 32px button like its neighbours, and the Settings title uses the same header row.

Requires Windows x64 and TeamSpeak 6.0.0-beta5, build 1791901251.

Validation includes the core, browser and native regression suites, plus live inspection of the server, channel chat and settings views. Context menus, private chats and stream views were not inspected live.
