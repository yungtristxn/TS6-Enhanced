Works with TeamSpeak 6.0.0-beta5.1, and keeps working the next time TeamSpeak updates itself.

- TeamSpeak's beta5.1 hotfix replaced its client files, so TS6 Enhanced 2.5.0 stopped loading without any message. 2.5.1 is verified with beta5.1. Because 2.5.0 can't start on beta5.1, it can't update itself: download and run this installer once.
- When TeamSpeak updates to a build a release wasn't verified with, TS6 Enhanced now keeps loading in **compatibility mode** instead of switching itself off. Everything that still starts keeps working. A feature that can't start stays off and is listed on the Updates tab of the TS6 Enhanced dialog.
- Updates keep working in compatibility mode, so you won't have to reinstall after a TeamSpeak update. A restart for an update keeps your window-close preference and lets TeamSpeak reopen your saved servers. Mute state and streams are restored automatically only on a verified build, and the update dialog says which applies.
- Setup installs on a newer TeamSpeak build in compatibility mode instead of refusing it. Uninstalling no longer depends on a specific TeamSpeak build.

Requires Windows x64 and TeamSpeak 6. Verified with TeamSpeak 6.0.0-beta5.1.

Validation includes the core, browser, native and installer suites against the installed beta5.1 client.
